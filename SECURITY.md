# Security Policy

## Supported versions

Security fixes are provided for the latest v1 release while v1 is current. Future major-version support will be stated here.

## Reporting a vulnerability

Do not open a public issue containing an exploit, credential, host, or sensitive log. Use GitHub's private vulnerability reporting feature for this repository. If it is unavailable, contact the repository owner privately through the contact method on their GitHub profile.

Include the affected workflow/script and version, impact, reproduction steps, and any suggested mitigation. Do not test against production systems without explicit authorization.
